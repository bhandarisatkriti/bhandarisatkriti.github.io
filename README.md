## Run locally

1. Clone this repository.
2. Open `index.html` in a browser.

There is no build step or package installation required.

## Deploy with GitHub Pages

1. Upload `index.html`, `README.md`, and `Satkriti.jpeg` to the root of the `bhandarisatkriti.github.io` repository. Keep the photo filename exactly `Satkriti.jpeg`.
2. In GitHub, open **Settings → Pages**.
3. Choose **Deploy from a branch**, `main`, and `/(root)`.
4. Wait for the deployment to finish.

The `.com.np` custom domain can be connected separately after the GitHub Pages URL is working.
