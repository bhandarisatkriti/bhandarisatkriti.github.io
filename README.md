# Satkriti Bhandari — Portfolio

A responsive, static personal portfolio built with HTML, CSS, and a small amount of JavaScript. No build tools or backend required.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in your browser.

## Deploy free with GitHub Pages
1. Sign in to GitHub as `bhandarisatkriti`.
2. Create a **public** repository named exactly `bhandarisatkriti.github.io`.
3. Upload `index.html` and `README.md` to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch **main** and folder **/(root)**, then click **Save**.
7. Wait a few minutes. The site should be available at:
   `https://bhandarisatkriti.github.io`

## Before publishing
- Check the email, LinkedIn, and GitHub links in `index.html`.
- Replace any project links that should point to specific repositories.
- Add a CV PDF only if you want it public, then link it from the hero section.
- Ensure every project description accurately reflects your contribution.
