Restaurant Ordering System

A single-restaurant ordering app. The Django backend is done and tested through Swagger: JWT login with customer, staff and owner roles, a menu with Cloudinary images, a cart, and orders that are saved in one database transaction with the total worked out on the server. Staff move orders through a fixed set of statuses, and customers pay by cash on delivery or eSewa (test mode), which the server checks with eSewa before marking an order paid.

Still to do: the Flutter app, automated tests, and Khalti payments.

Django REST Framework, PostgreSQL, JWT, Cloudinary, eSewa, Flutter
